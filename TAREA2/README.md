# **RedSocial**
Se ha identificado una necesidad de mejorar la comunicación y la interacción entre los estudiantes del Pascual Bravo. Aunque se cuenta con plataformas institucionales, a menudo son formales y no facilitan la conexión casual, el intercambio de conocimientos entre pares, la formación de grupos de estudio o la organización de eventos informales.

# Diseño de una Base de Datos con Estándares y Buenas Prácticas
> **Red Social Estudiantil Pascualina**  
> **Asignatura:** Bases de Datos 1*

> **Integrantes del Equipo:** Jonathan Montoya Machado - Johan Dario Martinez Echeverri*
---
## 📌 Descripción del Proyecto
Diseñar el modelo lógico de base de datos para la Red Social Estudiantil Pascualina, abordando el análisis de necesidades de la comunidad estudiantil y estructurando la información mediante el proceso formal de normalización,Diccionario de Datos y Entidades. Este modelo abarca la gestión de perfiles de usuarios, publicaciones, comentarios, reacciones, comunidades o grupos, eventos, habilidades, intereses, red de seguimiento entre estudiantes y un módulo de mentorías académicas.
