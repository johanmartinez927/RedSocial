# **RedSocial**
Se ha identificado una necesidad de mejorar la comunicación y la interacción entre los estudiantes del Pascual Bravo. Aunque se cuenta con plataformas institucionales, a menudo son formales y no facilitan la conexión casual, el intercambio de conocimientos entre pares, la formación de grupos de estudio o la organización de eventos informales.

## 📌 Descripción del Proyecto
En esta entrega se transiciona del modelo lógico al modelo físico funcional de la base de datos para la *Red Social Pascualina*. Se implementaron las estructuras necesarias mediante lenguaje DDL (Data Definition Language), asegurando la integridad referencial, la coherencia de tipos de datos y la correcta definición de claves primarias y foráneas.

---

## 🛠️ Tecnologías y Herramientas Seleccionadas

* **SGBD:** PostgreSQL 
* **Herramienta Gráfica / Cliente:** pgAdmin 4 
* **Lenguaje:** SQL (DDL)

> **Justificación breve del SGBD:** Se seleccionó PostgreSQL por su robustez en el manejo de relaciones complejas, rendimiento en consultas concurrentes y amplio soporte para tipos de datos avanzados, ideal para escalar la red social.
