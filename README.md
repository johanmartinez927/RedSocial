# RedSocial
Se ha identificado una necesidad de  mejorar la comunicación y la interacción entre los estudiantes del Pascual Bravo. Aunque se cuenta con plataformas institucionales, a menudo son formales y no facilitan la conexión casual, el intercambio de conocimientos entre pares, la formación de grupos de estudio o la organización de eventos informales.

# Red Social Pascualina - Modelo Conceptual de Base de Datos

## Integrantes del Equipo
Jonathan Montoya Machado -
Johan Dario Martinez Echeverri

## Descripción del Caso
Diseño del modelo Entidad-Relación (MER) para una red social universitaria del Instituto Pascual Bravo que facilite:
- Conexión casual entre estudiantes
- Intercambio de conocimientos entre pares
- Formación de grupos de estudio
- Organización de eventos informales
- Sistema de mentorías estudiantiles

## Entidades del Modelo
El modelo cuenta con 10 entidades principales:
1. *Estudiante*: Usuario principal de la plataforma
2. *Programa*: Programas académicos institucionales
3. *Perfil*: Identidad social del estudiante
4. *Interés*: Áreas de interés de los estudiantes
5. *Materia*: Materias del plan de estudios
6. *Publicación*: Contenido compartido en la red
7. *Grupo*: Comunidades de estudiantes
8. *Evento*: Actividades programadas
9. *Mentoría*: Sistema de orientación entre pares
10. *Mensaje*: Comunicación directa entre estudiantes
